# Simple FAQ Page

A beginner-friendly Frequently Asked Questions page built with HTML and CSS.

This project is based on the
[DevChallenges Simple FAQ challenge](https://devchallenges.io/challenge/simple-faq-challenge).

## Features

- Responsive FAQ card layout
- Semantic HTML structure
- Expandable FAQ sections using `details` and `summary`
- Ordered and unordered lists
- Clickable links
- Hover effects
- Keyboard focus styles
- Mobile-friendly design

## Technologies

- HTML5
- CSS3
- Git and GitHub

## How to run locally

1. Open the `Simple_FAQ` folder.
2. Open `index.html` in a browser.
3. Or use the Live Server extension in VS Code.
